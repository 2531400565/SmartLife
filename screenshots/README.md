# Screenshots

这里用于存放 App 界面截图，供 README 的「功能展示」引用。

## 需要的截图文件

| 文件 | 对应模块 |
|------|----------|
| `home.png` | 首页 Dashboard |
| `todo.png` | 待办 Todo |
| `focus.png` | 专注番茄钟 Focus |
| `timetable.png` | 课表 Timetable |

## 如何补充截图

1. 在模拟器或真机运行 App；
2. 对上述每个页面截图；
3. 将截图重命名为上表对应文件名，放入本目录即可。
