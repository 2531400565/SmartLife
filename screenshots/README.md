# Screenshots

将应用实机 / 模拟器截图放置于本目录，命名如下（与根目录 `README.md` 的引用保持一致）：

| 文件名            | 对应页面      |
| -------------- | --------- |
| `home.png`     | 首页 Dashboard |
| `todo.png`     | 待办 Todo    |
| `focus.png`    | 专注 Focus   |
| `timetable.png` | 课程表 Timetable |

图片补充后，`README.md` 中的「📱 Screenshots」一节将自动正常显示，无需改动其它文件。

> 本目录不提交任何伪造图片，仅保留说明与 `.gitkeep` 占位文件。
